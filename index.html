The application combines machine learning with a web-based interface to make crop disease detection more accessible.

LogGuard

LogGuard is a cybersecurity dashboard that analyzes uploaded log files to identify suspicious activities and potential security threats. It processes log entries using pattern matching and data analysis techniques. Its interactive dashboard helps users review detected events and understand potential risks.

Confidence Analyzer

Confidence Analyzer is a web application that uses AI to assess confidence-related visual cues through a webcam. It analyzes facial expressions, hand gestures, and body posture to generate a confidence score. The application also provides AI-generated recommendations and session history to help users reflect on their presentation and communication.
